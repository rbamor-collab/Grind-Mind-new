Building a Monthly Sales Report

Apply essential Excel formulas and functions from Module 2 (including SUM, AVERAGE, COUNT, MAX, and MIN) by organizing and computing raw sales data into a formatted spreadsheet.

📋 Challenge Requirements:

  • Data Entry: Input the raw sales data provided below into an Excel sheet with proper column headers.
  • Basic Math Operations: Compute the Total Sales per item (= Quantity Sold × Unit Price) using cell references.
  • Excel Functions:
    • Calculate total revenue using =SUM()
    • Calculate average sales per product using =AVERAGE()
    • Determine total product items counted using =COUNT()
    • Find peak sales using =MAX() and lowest sales using =MIN()
  • Formatting & Polish: Apply currency formatting (₱), cell borders, header shading (Excel Green), and proper cell alignments.

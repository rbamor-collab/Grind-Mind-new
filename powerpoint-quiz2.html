Designing a 5-Slide Pitch Deck

Put your visual design skills into practice! Apply color themes, typography rules, SmartArt graphics, and icons from Module 2 to transform the raw proposal text below into an engaging, professional 5-slide pitch deck.

📋 Instructions for Learners:

  • Theme & Hierarchy: Review the 5-slide raw data below and set up a consistent color theme and font hierarchy across all slides.
  • SmartArt & Icons: Use PowerPoint icons and SmartArt graphics to visually represent data and process steps (Lessons 2.1 & 2.2).
  • Design Polish: Ensure proper contrast, alignment, and whitespace across all 5 slides.
  • Submission: Save your presentation file (.pptx) and upload it using the form below.

📄 Raw Pitch Deck Data:
